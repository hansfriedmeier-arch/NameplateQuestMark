# NameplateQuestMark (WoW Forever)

Zeigt ein **„!“ auf den Namensplaketten von Gegnern, die zu einer deiner aktiven Quests gehören** – so siehst du
sofort, welche Mobs du für deine Quests brauchst.

## Funktionen
- „!“ an feindlichen Namensplaketten, wenn das Spiel den Gegner einer aktiven Quest zuordnet.
- Funktioniert mit den Standard-Namensplaketten und mit BetterNamePlates.
- Verschwindet von selbst, sobald die Quest fertig ist.
- Sparsam: prüft nur sichtbare Plaketten, nur wenn sich etwas ändert.

## Benutzung
Einfach installieren – es gibt nichts einzustellen. Namensplaketten für Gegner müssen an sein (Taste **V**).
`/nqm` listet zur Fehlersuche, was das Spiel für jede sichtbare Plakette meldet.

## Installation
Unter [Releases](../../releases) die neueste Zip laden und nach `World of Warcraft/_forever_/Interface/AddOns/` entpacken.
